# OpenRig: central lead and specialist teams

OpenRig team guidance is shared through the `openrig-team` skill. Use it when a
user asks for a coordinated specialist team or sustained work benefits from one.
Use `ai-team roles` to see the roster. A normal small task need not start a team.
Read the skill before preparing or starting a project team. `ai-team` keeps the
reusable roster central and generates project-specific runtime state outside Git.
Start only relevant agents; specialist names do not expand authorised app scope.

Use the installed `rig` and `ai-team` commands; do not run upstream install/setup,
upgrade commands, add duplicate MCPs or enable the broad-access kernel. Respect
existing client settings. New team launch may add upstream workspace trust and
managed project guidance; inspect these changes and preserve team instructions.
No automatic deployment, publishing, transcript ingestion or background task
assignment is enabled. Global installation is availability, not proof of use.

On native Windows, `ai-team --host SSH_ALIAS ...` runs the team on an authorised
macOS/Linux host with ai_setup installed. Project paths are on that host. No WSL
or native Windows OpenRig runtime is installed. See the installed
`~/.local/share/ai-setup/openrig-team/README.md` for operation and verification.
