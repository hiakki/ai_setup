# Authored agent roles

Create project-neutral custom roles here as `<name>.md`, with YAML `name` and
`description` frontmatter followed by Markdown instructions. Search the central library
before creating a role. Keep original-provider roles at their provider and select them
through `manifest.json`.

The `agents` installer component creates the Claude Markdown and Codex TOML adapters.
README.md is documentation and is not installed as a role. Private roles require an
authorized private source; do not publish them here.
