# Frontend reference catalog

Reviewed 17 October 2026 from two user-supplied reels and the linked provider
pages. This is a curated navigation guide, not a benchmark or a copied provider
library. Recheck availability, pricing and reuse rights before relying on a service.

| Original provider | Useful for | Use and limits |
| --- | --- | --- |
| [Scrolltide](https://www.scrolltide.co/) | Website and scrolling/interaction inspiration | Study rhythm and transitions selectively; do not infer implementation or performance from a showcase. |
| [Navbar Gallery](https://www.navbar.gallery/) | Navigation patterns | Compare hierarchy and responsive navigation; test keyboard and open-menu behavior in the actual app. |
| [Footer Design](https://www.footer.design/) | Footer organization | Adapt information hierarchy to real links and legal content; do not reproduce another brand's assets. |
| [CTA Gallery](https://www.cta.gallery/) | Calls to action | Study hierarchy and wording; visual prominence does not prove conversion improvement. |
| [Supahero](https://supahero.io/) | Hero-section references | Use for an appropriate landing page, not as a default dashboard layout. |
| [3dicons](https://3dicons.co/) | Optional 3D illustration assets | Check the chosen asset's license and delivery size; use only when it clarifies the product. |
| [Refero](https://refero.design/) and [official design skill](https://github.com/referodesign/refero_skill) | Real screens, flows and design-system research | The reel showed Refero Styles/design context. Current official skill separates bundled guidance from live MCP research; live research requires an eligible paid plan. Optional, not required by this setup. |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Searchable design/style, typography, palette and stack guidance | Open-source MIT core; treat generated suggestions as candidates. Selected globally on 19 October 2026 at reviewed pin `56ea9cf174ed86786187daa9de0e6247cb0747e4` with scripts/data/references and license. A copied SKILL.md alone is incomplete; no app dependency or paid API was added. |
| [21st.dev](https://21st.dev/) | React component and layout starting points | Review each chosen component's license, dependencies and accessibility; adapt to the existing design system. A catalog entry is not an audited production component. |
| [Motion for React](https://motion.dev/docs/react) | Purposeful layout, gesture and coordinated animation | An application dependency when needed, not a global agent prerequisite. Keep simple transitions in CSS; implement reduced-motion behavior. |

The complete workflow is in [frontend-design-workflow.md](frontend-design-workflow.md).
Browse only the providers relevant to the current design problem. No paid account,
new MCP, source upload or per-project skill installation is required to use it.
Provider code, screenshots, videos and commercial content are not cached here.

## Provenance and evidence limits

- [First reel](https://www.facebook.com/share/r/1Ex2VKwgbr/) — Vishnu.ai,
  “7 websites to make your vibe coded websites premium”; resource names were
  checked against video frames and provider pages. The frame caption spelling
  “Scrolltite” resolves to the displayed Scrolltide provider.
- [Second reel](https://www.facebook.com/share/r/1EnAvczeKW/) — Hamza Bin Zia;
  the demonstrated combination is Claude Code, UI UX Pro Max, Motion and 21st.dev.
  Tool names are verified; speed/quality marketing claims are not validated.
- The adopted lesson is to research fitting references, define a coherent design
  system, adapt components, add purposeful motion and verify the rendered workflow.
  These resources have not been benchmarked against each other, and this update
  does not establish a measured improvement in any existing application's UI.
